# Davi Janisch Maia

Software engineer in Florianópolis, Brazil, working on backend architecture and applied AI. I build systems that
put LLMs, agents and document intelligence into production: reliable, observable and secure, not demos. Before
that I wrote smart contracts and tokenization platforms, which still shapes how I think about trust and
verification in distributed systems.

- **Document intelligence pipelines.** Extracting and structuring technical and industrial documentation at scale
  for enterprise clients.
- **Confidential AI infrastructure.** Processing sensitive data on GCP Confidential VMs (AMD SEV-SNP) with
  least-privilege access and Vault Transit encryption.
- **AI-assisted engineering.** Building and mentoring around AI-assisted development (Claude Coåde, Cursor) on a  
  growing team.
- **Tokenization (background).** Multi-chain platforms with on-chain compliance (T-REX/OnchainID), wallet
  infrastructure and KYC for real-asset offerings.

## Side projects

| Project | What it is | Result |
